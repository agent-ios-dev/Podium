# Podium 0.5.0: 8 ГиБ, интернет и Cydia

Эта версия сохраняет исправленный накопитель 8 ГиБ и добавляет сеть и Cydia в гостевую iOS 6.1.6 / 10B500. Саму IPSW нужно импортировать отдельно, как раньше.

## Установка

1. Подпиши новую IPA своим обычным способом и установи поверх предыдущего Podium с тем же идентификатором приложения. Не удаляй приложение перед обновлением: удаление может стереть его данные.
2. Включи JIT и запусти виртуальный iPod. При первом запуске существующий образ обновляется через временный файл; стирание гостя не требуется. Во время подготовки нужен запас места на настоящем устройстве для временного образа.
3. Дождись загрузки. Cydia автоматически регистрируется на домашнем экране; её первый запуск может занять дополнительное время.
4. В Safari начни с `http://example.com/`. Wi-Fi внутри виртуального iPod настраивать не нужно: используется интернет устройства, на котором запущен Podium.

Новые Virtual iPod сразу получают Cydia и сеть. Существующие приложения, настройки и записи об установленных DEB сохраняются при обновлении. Уже имеющиеся файлы bootstrap не заменяются; новые записи dpkg добавляются к существующим. Установленная тобой Cydia и её настройки также сохраняются.

## Что реализовано

- Гостевая служба `podium_netd` создаёт штатный интерфейс XNU `utun`, задаёт IPv4-адрес, маршрут и DNS, публикует состояние сети для CFNetwork.
- IP-пакеты проходят через отдельный вызов эмулятора. Хостовая часть обслуживает исходящие TCP/UDP-соединения через Network.framework, а запросы DNS A — через резолвер хоста. Входящие порты на хосте не открываются.
- TCP учитывает подтверждения и окно приёма, повторяет неподтверждённые пакеты и ограничивает объём ожидающих данных. Это первоначальная реализация IPv4; IPv6, фрагментация IP и все варианты сетевых протоколов не реализованы.
- В образ добавлен legacy bootstrap Cydia: само приложение, `cydo`, dpkg, библиотека APT, оболочка и зависимости. Проверки подписи гостевого ядра уже отключены исходным Podium. Гостевая служба выполняет штатную инициализацию Cydia и `uicache`.
- При подготовке гостевого диска автоматически ставятся три офлайн-пакета: `mobilesubstrate` 0.9.6301, `com.saurik.substrate.safemode` 0.9.6001 и `preferenceloader` 2.2.6. Их файлы и записи dpkg добавлены в образ; данные и настройки установленных пользователем пакетов при обновлении сохраняются.
- Substrate запускается штатным для iOS 6 способом: `launchd.conf` вызывает `cynject`, который загружает `SubstrateLauncher` в `launchd`; при обновлении образа хук добавляется с сохранением остальных настроек. Строка XNU `external_modification` с меткой `noop` — статистическое сообщение о создании удалённого потока, а не результат отказа. Интеграционный тест загружает в SpringBoard безвредный пробный tweak и проверяет его файловый маркер после реального запуска iOS.
- Полный набор функций джейлбрейка физического устройства здесь не воспроизводится. Твики, зависящие от отсутствующего оборудования, особых патчей ядра или конкретной версии iOS, всё равно нужно проверять отдельно.

Safari и Cydia остаются приложениями iOS 6: современные HTTPS-сертификаты, шифрование, JavaScript и неработающие старые репозитории могут мешать загрузке отдельных страниц. Соединение с интернетом не обновляет браузер и библиотеки iOS.

## Сборка

На Mac с Xcode и XcodeGen:

```bash
brew install xcodegen
bash build-8gib-ipa.sh
```

Скрипт сначала собирает гостевую ARMv7-службу для iOS 6 и подписывает её старым форматом, затем собирает приложение Podium для современного устройства. Итоговая IPA не подписана установочным сертификатом. Минимальная версия хостовой iOS — 17.0; для эмуляции нужен JIT.

Для повторного получения bootstrap:

```bash
python3 GuestTools/prepare-jailbreak.py
```

Скрипт использует закреплённые версии и сверяет SHA-256 каждого скачанного архива. Гостевой bootstrap получен из [Legacy iOS Kit](https://github.com/LukeZGD/Legacy-iOS-Kit/tree/33dcbfcf4d8791268292e1009e2955e3f02b4785/resources/jailbreak); источники и контрольные суммы записаны в `ORIGIN.txt` внутри ресурса. Авторы Cydia/Substrate — Jay Freeman, PreferenceLoader — Sam Bingner; [исходники Cydia](https://git.saurik.com/cydia.git). Скрипты установки DEB-пакетов не запускаются. Лицензии и сведения об авторах включённых пакетов сохранены в payload. Эксплойты и untether-службы для физического устройства не включены.

## Диагностика

Сообщения сети и Cydia доступны в журнале Podium в Developer Settings. Нормальная конфигурация выдаёт `utun configured 10.0.2.15 -> 10.0.2.2`; регистрация приложения — `Cydia uicache completed`.

Workflow `Diagnose actual iPod kernel boot` запускает настоящую iOS на новом диске, проверяет сохранение данных при обновлении, запрос через гостевые BSD-сокеты, получение страницы через CFNetwork и запуск Safari/Cydia. В тестовом режиме открытие приложений автоматическое; в обычной IPA эти действия не выполняются. Прошивка Apple скачивается только для временной проверки и в архив проекта не входит.
